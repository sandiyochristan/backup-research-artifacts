ATTACK MODEL:
Any app with READ_CALENDAR permission can exploit this SQL injection to:
1. Extract sync state data including Google account sync tokens
2. Extract full database schema
3. Access internal tables not exposed through the public API
4. Bypass view restrictions (e.g., lastSynced filter)
5. Extract user timezone/location information

This data is NOT accessible through the normal CalendarProvider API, 
even with READ_CALENDAR permission granted.
